# GameruleSync

## language [[Zh](https://github.com/YHyhmc/GameruleSync/edit/main/README.md)|[EN](https://github.com/YHyhmc/GameruleSync/edit/main/README_en.md)]

## Overview

This plugin lets you play maps such as [MiniGames](https://github.com/wifi-left/Map-MiniGames) on plugin-based server software like Paper.

### Core Mechanism

It listens for gamerule changes and automatically syncs them to all loaded worlds (a feature exclusive to plugin-based servers such as Paper).

### Compatibility

I tested Paper 26.2 and Purpur — most gameplay works fine with basically no bugs.

Cross-version play with ViaVersion also works (1.21.11 client on a 26.2 server).

Plugin compatibility: in theory, any plugin works as long as it doesn't break world loading or commands.

### Installation

You need a clean, unopened `MiniGames` map (otherwise you may run into weird bugs).

Put this plugin into the `plugins/` directory.

Restart the server and wait for the MiniGames datapack to print its output.

Now you're ready to play.
