# GameruleSync

## language [[Zh](https://github.com/YHyhmc/GameruleSync/edit/main/README.md)|[EN](https://github.com/YHyhmc/GameruleSync/edit/main/README_en.md)]

## 功能概述

这个插件让你在Paper等插件端也可游玩[MiniGames](https://github.com/wifi-left/Map-MiniGames)等地图

### 核心机制

监听世界规则变动，自动同步到所有已加载世界（Paper等插件端独有特性）

### 兼容性

我测试了26.2的Paper与Purpur大部分的玩法都可以游玩，基本没有bug

安装ViaVersion跨版本也没问题（1.21.11客户端，服务器26.2）

兼容的插件：理论上只要不破坏世界加载与命令就兼容

### 安装方法

你需要一个纯净未开服的的`MiniGames`地图（不然会有奇妙bug）

将本插件放入放入 `plugins/` 目录。

重启服务器，等待MiniGames数据包输出内容即可

此时你就可以游玩了。
